# 原版武将名字体

HH优化的武将名使用本机原版资源中的 `FZLBGBK` 常规字体，替换原来的额外加粗效果，保留版本前缀颜色。名字字号为 18px、行高 21px、字距 3px，以原版 224px 牌高、22px 名字字号的比例换算，接近参考图的大小与疏密。主将名和暗将名按势力底栏自动水平居中，避免放大文字后仍沿用旧的固定框宽而偏移。OL 势力字与名字共用同一组左右边界及竖排中心线，以自身中心放大 10%，保留主题的颜色和字形。

原版代码将 `rB.SemiBold` 映射到 `fzlbgbk`，从 `res/assets/fontApp/FZLBGBK.ttf` 加载；对局武将名通过 `jx.Create` 使用此默认字体，字重设置为非加粗。字体实际字重为 400。

完整字体从 `E:/AI/sanguosha/sanguosha2/yoka.game_g_android_4.0.2.apk` 的缓存键 `d54ce33c` 提取，转换为 WOFF2 后随扩展离线提供，覆盖 22033 个字符。原文件、转换文件的哈希与来源见 `assets/general-font/sources.json`。已核对完整字符映射及代表字形的轮廓和字宽，转换不替换字形。

样式作用于对局、开局选将及全屏武将界面共用的武将名节点，包括主副将和暗将名。字体采用独立的 `hh-source-general` 名称，不重定义游戏的全局字体；缺字时沿用原有字体后备。

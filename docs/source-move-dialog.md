# 原版移牌及排序弹窗

素材来自 `E:\AI\sanguosha` 内 Unity 客户端的 `Assets/Res/Picture/SkillWin/`，资源包为 `3e783501a60dace2`。`assets/move-dialog/sources.json` 记录原始路径、尺寸和 SHA-256：

- `skill2025_bg_big.png`：半幅背景，左右镜像拼合后裁去底部 45 像素透明留边，生成 `panel.png`。
- `skill2025_bg_card.png`：棕色纹样空槽；右侧增加 16 像素透明间隔，生成重复平铺的 `slot-tile.png`。
- `skill2025_title_vertical.png`：纵向行名背景。
- `skill_window_close.png`：标题右侧的放大图标。

`src/ui/sourceMoveDialog.js` 在原生 `chooseToMove`、`chooseToMove_new` 弹窗打开后装饰已有节点，牌区连同行名整体居中。标题使用实际技能名；不同技能仍使用自身的牌区名称。窗口大小、行数和分组数共同决定牌面尺寸，放大图标可以切换较大布局。牌槽按相同尺寸及间隔平铺，两行保持对齐；隐藏原提示及“全选”条。

保留原生卡牌、容器、事件回调和结果数组。空槽由伪元素绘制，不插入真实卡牌列表；拖动副本继承相同缩放，原生移动和交换动画继续使用自身的位移。关闭弹窗时解除本模块的尺寸及节点观察器。

背景上下各增加 24 像素余量，牌面尺寸和间隔沿用原布局；小窗口按可用高度收缩余量，避免弹窗超出屏幕。

“更换光标+loading框”最后一项仍为 `onlineUI`，预览及背景 `image/ui/dialog/dialog5.png` 与 `panel.png` 相同。此项使用全宽背景，并按内容实际高度扩展；首行标题放在背景顶部，避免原来的固定 200 像素高度容纳不下卡牌。其余选项保留原有样式。

普通选牌弹窗统一在卡牌上应用当前手牌的缩放比例，牌区容器不再叠加缩放，避免不同容器或外部样式令卡牌及面板偏大。显式小尺寸牌区继续保持较小尺寸；窗口变化时同步刷新缩放并重新测量面板高度。规则覆盖各 loading 主题及新旧牌区布局，不按武将、技能或牌数区分；选将、移牌排序和连续展示继续使用各自布局。

卡牌尺寸由 `src/ui/dialogCardSizing.js` 在弹窗内容测量前，直接写入卡牌及牌区节点的数值缩放，兼容诗笺 Android 客户端使用的编译本体。卡牌弹窗不再依赖竞技场是否还带有选将标记，也不依赖 CSS 选择器或 CSS 变量；节点上遗留的大尺寸缩放会被统一校正。选将中的武将按钮不作处理，移牌排序及连续展示保留各自缩放。

`src/ui/dialogVisibility.js` 为原生弹窗、技能窗口、移牌确认框、技能说明及带对话框角色的自定义窗口统一添加“隐藏／显示”按钮。按钮位于窗口右上；临时隐藏背景和内容时仍保留恢复按钮，原有选牌、牌序、技能结果及确认回调不变。隐藏区域不接收点击和键盘焦点，允许继续查看、选择场上角色。重新打开窗口会恢复显示，关闭后回收本模块状态；原生“隐藏窗口”控件保留其事件清理流程，并隐藏重复入口。嵌套窗口共用一个按钮，重建内容后补回按钮，窗口变化时沿用原布局调整位置。

验证使用当前游戏的真实两种移牌事件、弹窗与移动/交换动画方法，覆盖桌面、横屏、竖屏、单行、三行及多分组布局，检查居中、牌面与空槽对齐及旧条带隐藏。实际拖动、交换排序、放大、确认、取消、自动选择和确认限制均通过；另校验资源哈希并运行扩展测试。

# 开局AI主公盲狙

“扩展 → HH优化 → 开局AI主公盲狙”默认开启，可随时关闭。适用于离线身份局中已明置的 AI 主公，自动托管的主公也可使用；真人手动控制、联机、国战、紫色身份及谋攻身份模式沿用原有逻辑。

场上没有存活、在场且明确偏反的角色时，从存活、在场、未明身份且没有偏忠证据的角色中选一个目标。使用原生 `get.threaten` 的武将技能威胁值及攻击距离加权：`0.9 × 威胁 + 0.1/距离`，距离至少取 1。仇恨占 90%，距离占 10%，保留原始威胁差异，取消原有 `威胁/(1+威胁)` 的压缩；较远但仇恨较高的角色可以超过相邻角色。权重最高者当选，同分沿用座位顺序。只使用公开的威胁与距离，不读取未知身份或隐藏手牌。目标保持锁定，不因后续权重小幅变化而反复切换；目标死亡、离场或表现偏忠后，重新加权选择。

通过身份模式的 `_status.ai.customAttitude` 接入原生 AI：主公对盲狙目标暂时按敌方评分，对已有偏忠证据的角色按友方评分。有存活明反时暂停盲狙，对明确偏反的在场角色按敌方评分，优先处理明反。卡牌、主动技能、转换牌和基于态度判断的响应技能共用这一入口，保留原本的距离、可用次数、消耗、存活及收益检查。

身份倾向依据已公开的出牌、技能和伤害/回复行为累计：明确帮助主公或已有偏忠倾向的角色增加偏忠证据，明确伤害或妨碍他们增加偏反证据。自身吃桃、装备等自用操作及攻击未知身份角色不单独确定阵营；群体行为按目标数减权，同一次使用及其伤害不会重复计入，借刀强制出杀及连环波及不当作新的主动表态。实际明置的忠臣排除出盲狙候选。暂停期间继续记录行为，新的明反及偏忠角色会参与之后的启停和选人判断。

目标表现偏忠时立即换人；只要还有在场存活的明反，就优先打明反。最后一名在场明反死亡或离场后，重新加权盲狙未表态的存活角色；盲死一个反贼、其他反贼仍未暴露时继续盲狙。死亡角色的公开身份和旧行为证据不会永久关停机制，明反重新回场时再次暂停盲狙。行为倾向是推测，内奸的伪装也按其公开行为处理。关闭开关立即停止态度修正，游戏结束清除本局状态。

检查覆盖非相邻高仇恨目标、锁定、偏忠换人、明反优先、盲死反贼后继续、多名明反全部死亡后恢复、暂停期间更新证据、离场与回场、开关和模式隔离、强制行为及群体行为去重，并运行原生身份态度、`Get.effect_use`、`Basic.chooseCard`、`Basic.chooseTarget` 和强袭技能 AI，验证卡牌及技能在明反与盲狙目标间切换，且保留生命消耗等原有判断。触发内容经过实际 `AsyncCompiler` 检查，未完成真实游戏整局验证。

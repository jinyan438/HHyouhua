# 开局AI主公盲狙

“扩展 → HH优化 → 开局AI主公盲狙”默认开启，可随时关闭。适用于离线身份局中已明置的 AI 主公，自动托管的主公也可使用；真人手动控制、联机、国战、紫色身份及谋攻身份模式沿用原有逻辑。

开局没有明确反贼倾向时，从存活、在场、未明身份且没有偏忠证据的角色中选一个目标。使用原生 `get.threaten` 的武将技能威胁值及攻击距离加权：`0.65 × 威胁/(1+威胁) + 0.35/距离`，距离至少取 1；权重最高者当选，同分沿用座位顺序。只使用公开的威胁与距离，不读取未知身份或隐藏手牌。目标保持锁定，不因后续权重小幅变化而反复切换；目标死亡、离场或表现偏忠后，重新加权选择。

通过身份模式的 `_status.ai.customAttitude` 接入原生 AI：主公对盲狙目标暂时按敌方评分，对已有偏忠证据的角色按友方评分。卡牌、主动技能、转换牌和基于态度判断的响应技能共用这一入口，仍保留原本的距离、可用次数、消耗、存活及收益检查。不会强制出牌或发动亏损技能；只修正开局因未知身份态度接近零而放弃攻击、控制或取牌的判断。

身份倾向依据已公开的出牌、技能和伤害/回复行为累计：明确帮助主公或已有偏忠倾向的角色增加偏忠证据，明确伤害或妨碍他们增加偏反证据。自身吃桃、装备等自用操作及攻击未知身份角色不单独确定阵营；群体行为按目标数减权，同一次使用及其伤害不会重复计入，借刀强制出杀及连环波及不当作新的主动表态。实际明置的忠臣排除出盲狙候选，实际明置的反贼直接结束盲狙。

目标表现偏忠时立即换人；任何角色出现明确偏反证据时，本局盲狙永久结束并恢复原生身份 AI，即使该角色之后死亡也不重新开启。角色死亡后明置为反贼也会结束盲狙。行为倾向是推测，内奸的伪装也按其公开行为处理。关闭开关立即停止态度修正，游戏结束清除本局状态。

检查覆盖加权、锁定、偏忠换人、非目标偏反退出、身份明置、死亡/离场、开关和模式隔离、强制行为及群体行为去重，并运行原生身份态度、`Get.effect_use`、`Basic.chooseCard`、`Basic.chooseTarget` 和强袭技能 AI，验证杀和技能能选择目标，且保留距离与生命消耗限制。触发内容经过实际 `AsyncCompiler` 检查，未完成真实游戏整局验证。

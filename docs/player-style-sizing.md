# 武将宽度自动适配

“武将牌样式”只保留“武将宽度(px)”，范围 80–200，默认 136。改变宽度时，牌面高度保持原样，画像继续使用 `cover` 填充。

以确认的当前 136 像素样式为固定基准，按牌宽增量调整画像、边框和光效，保持左侧栏及牌面高度：

| 基准参数 | 136 像素时的值 |
| --- | --- |
| 边框宽度 | 401% |
| 发光宽度 | 220px |
| 发光左偏移 | -50px |
| 勾玉右偏移 | 134px |
| 边框左偏移 | -15px |
| 势力图片左偏移 | 13px，沿用对应主题 |
| OL 势力字、武将名左右内边距 | 各 26%，与势力底栏一致 |

七个原独立设置已移除，历史保存值不再参与计算。勾玉固定在原来的左侧位置，右偏移等于 `134 + 当前宽度 - 136`，护甲保留原右侧间距。武将名和暗将名按势力底栏的左右边界自动居中，文字框宽度随栏宽计算，取消旧的 18px 固定框宽、靠边对齐和主题横移，避免字号放大后向左偏。OL 势力字与名字使用同一组边界和竖排居中方式，共用一条中心线；势力字以框的中心放大，不移动中心线。其他主题的势力图片沿用素材布局。单将画像保留当前主题的左右内边距，不再使用随宽度变化后产生留缝的百分比宽度；双将继续使用原布局。

当前 online 金龙边框图片为 228×288，其中竖边中心位于横坐标 32.5 和 203.5，可见跨度为 171。牌宽增量需换算为整张素材的增量，同时补偿透明左留边，才能让左边固定、右边正好扩展相同距离。

光效按回合、选中与目标素材中可见竖边的位置分别校准。横向伸展以可见左边为锚点，避免中心缩放造成左移；不改变原生动画帧、颜色、节奏或高度。136 像素时保留原来效果。

修改宽度会立即刷新对局与预览共用的样式，清除旧的开局尺寸缓存。选将及武将详情的勾玉使用实时宽度变量补偿坐标，避免窗口比例变化或再次修改宽度后偏移。三人等少人数布局同样应用宽度。

回归检查覆盖 80、136、160、200 像素，检查画像间距、边框可见左右边及三种光效的左右边位置；同时保留设置精简、旧值忽略与勾玉窗口缩放检查。武将名检查使用实际主题和原版字体样式，确认不同牌宽及缩放下的文字行中心与势力底栏中心重合。

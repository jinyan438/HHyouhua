# 武将牌尺寸自动适配

“武将牌样式”相邻提供“武将宽度(px)”与“武将高度(px)”。宽度范围 80–200，默认 136；高度范围 120–300，默认 180。两项独立保存，失去焦点时立即刷新，空白或无效输入恢复默认，超出范围自动限制到边界。画像继续使用 `cover` 填充。

以确认的当前 136×180 像素样式为固定基准，按牌宽增量调整画像、边框和光效，保持左侧栏的横向位置：

| 基准参数 | 136 像素时的值 |
| --- | --- |
| 边框宽度 | 401% |
| 勾玉右偏移 | 134px |
| 边框左偏移 | -15px |
| 势力图片左偏移 | 13px，沿用对应主题 |
| OL 势力字、武将名左右内边距 | 各 26%，与势力底栏一致 |

七个原独立设置已移除，历史保存值不再参与计算。勾玉固定在原来的左侧位置，右偏移等于 `134 + 当前宽度 - 136`，护甲保留原右侧间距。武将名和暗将名按势力底栏的左右边界自动居中，文字框宽度随栏宽计算，取消旧的 18px 固定框宽、靠边对齐和主题横移，避免字号放大后向左偏。OL 势力字与名字使用同一组边界和竖排居中方式，共用一条中心线；势力字以框的中心放大，不移动中心线。其他主题的势力图片沿用素材布局。单将画像保留当前主题的左右内边距，不再使用随宽度变化后产生留缝的百分比宽度；双将继续使用原布局。

当前 online 金龙边框图片为 228×288，其中竖边中心位于横坐标 32.5 和 203.5，可见跨度为 171。牌宽增量需换算为整张素材的增量，同时补偿透明左留边，才能让左边固定、右边正好扩展相同距离。

光效已替换为 OL 原版 `FX_PaiJu_ZuoWei` 的绿、黄橙、红、蓝四种座位光框，来源与转换方式见 [光框说明](source-player-glow.md)。四种素材统一可见竖边，左侧及顶部外扩 2px，右侧外扩 3px；宽度变化时固定左边、向右扩展。高度变化时同步调整光框高度与顶部偏移，底边始终位于牌面下方 1px；红色结算框和牌面遮罩同步适配高度。

online、一将成名与名将杀的整牌边框以牌面顶部为纵向缩放锚点，随高度调整；十周年、移动版与欢乐三国杀的势力装饰保留原尺寸。online 势力底栏向下延伸，文字字号不缩放。七人、八人布局中纵向居中的座位按设置高度重新居中。

修改宽度或高度会立即刷新对局与预览共用的样式，清除旧的开局尺寸缓存。没有可测量的对局武将时，预览也读取已保存的宽高。选将及武将详情的勾玉使用实时宽度变量补偿坐标，避免窗口比例变化或再次修改宽度后偏移。三人等少人数布局同样应用宽高设置。

宽度回归检查覆盖 80、136、160、200 像素，检查画像间距、边框可见左右边及三种光效的左右边位置；高度检查覆盖 120、180、240、300 像素及输入边界、独立保存和预览回退。实际浏览器验证六种主题在普通、少人数布局下的 144 组宽高组合，确认头像、预览、光效底边、遮罩和纵向居中同步变化。武将名检查保留文字行中心与势力底栏中心重合的要求。

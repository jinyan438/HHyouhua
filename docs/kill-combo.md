# 连斩播报

开启扩展原有的“启用连斩特效”即可使用。击杀触发后先准备资源，再同时开始动画和对应音效，动画完成后继续结算。角色头顶的额外文字仍由“显示连斩文字”控制，不影响全屏动画。

| 连斩 | 画面文字 | 动画时长 |
| --- | --- | --- |
| 一破 | 龙战于野 | 2.333 秒 |
| 双连 | 飞龙在天 | 2.733 秒 |
| 三连 | 亢龙有悔 | 2.667 秒 |
| 四连 | 天下无敌 | 2.667 秒 |
| 五连 | 威震天下 | 3.2 秒 |
| 六连 | 天崩地裂 | 3.2 秒 |
| 七连 | 毁天灭地 | 3.467 秒 |

入口为 `hh-features.js` 的 `_HH_lianzhan_`。原有 `dieBegin` 触发、重复死亡事件保护、一破标志、七连封顶和回合结束清理规则保持原样；原来的固定 4～4.2 秒延迟改为等待实际动画。癫狂屠戮、万军取首不在本次替换范围。

`src/effects/killCombo.js` 使用独立 Canvas / WebGL 播放原始 Spine 4.0.56 时间轴，同时支持 Region 和加权 Mesh、旋转打包图集与加色混合。`src/libs/spine4-core.js` 为模块内运行库，不赋值 `window.spine`，不替换十周年 UI 动画及动态皮肤所用运行库。显示层不接收点击，播放结束或游戏结束后清理；连续触发排队播放，纹理缓存最多保留两套资源。

音频调用无名杀的 `game.playAudio`，沿用游戏音量及静音设置。七个文件是原始 `.ogg`，未伪装成 MP3。旧 `audio/a_*.mp3` 保留，但连斩入口不再引用它们。资源或 WebGL 无法加载时保留对应的新音效，并有结束超时保护，避免卡住结算。

37 个原始文件位于 `assets/kill-combo/`：7 个骨骼、7 个图集描述、16 个图集页面、7 个音效。来源为用户本地三国杀客户端已导出的完整播报，`sources.json` 保留路径、缓存键、大小与 SHA-256，运行库保留原版权及许可声明。集成只将运行库末尾的全局赋值改成模块导出，原始骨骼、图集、音效本体未改动。

验证：`node --test tests/kill-combo.test.mjs` 检查原始文件哈希、运行库隔离、622 个时间点的实际渲染几何、播放排队、音效对应、缓存回收、取消、隐藏视图结束保护、加载失败降级以及实际技能触发逻辑。

# 武将界面

重启游戏后，点击右上角菜单中的“武将”。六套菜单主题均提供此入口，沿用各自的排列方式。

左侧列出游戏已注册的武将包，包括关闭的武将包及扩展包；“全部”合并重复武将。右上角可按武将名字、内部编号或技能名搜索，也可筛选全部、已启用或已禁用武将。列表分批加载，左右区域可分别滚动。

筛选使用界面内的金棕色下拉菜单，直接在按钮下方展开，不调用系统选择弹窗。选择后立即筛选并收起，点击外部、滚动列表或按 Esc 均可收起；键盘方向键与 Home/End 可切换选项。

长按左侧武将包约 0.6 秒开启或关闭，与设置 → 武将页的“开启”共用数据；电脑也可右键切换。关闭的分类按钮及其武将半透明显示；单独禁用的武将保持灰色。整包开关不改动个人禁将，也不关闭扩展本体的其他功能。滑动或长按松手不会误选分类。

分包读取原生 `lib.characterSort` 及其译名，以原版金色横向分隔条隔开，显示分包名、启用数量和开关，不添加圆形徽章或集齐奖励。分包开关沿用设置页的规则：该组有任一未禁用武将即显示开启，关闭会禁用全组，重新开启则解除全组禁用。整包关闭时仍可调整其中的个人禁将与分包设置，须开启整包后才可用于选将。

点击武将进入详情。横屏左侧武将放大至接近整屏高度，保留开局选将的牌面比例及当前主题；右侧使用原版素材显示“技能、攻略、故事”页签、技能按钮及说明，下方为皮肤缩略图。返回列表保留分类、搜索和滚动位置。故事读取本地生平；攻略读取本地 `characterGuide` 或 `characterStrategy`，没有资料时显示“暂无攻略”。

横屏详情按左侧容器实际可用高度和宽度计算牌面尺寸，沿用开局记录的宽高比例，并与左侧区域底部对齐；底部保留安全区。再比较牌面与外观节点的真实渲染宽度校准缩放，避免额外缩放后外观小于容器。观察左侧区域的尺寸变化；竖屏恢复上下排列时清除横屏固定尺寸。

技能说明使用原版“主、被”标识：有 `enable` 的技能标为主动，有 `trigger` 的技能标为被动，同时具备则显示两种；另按定义显示主公技、限定技、觉醒技、锁定技、转换技等标识，不执行技能内容或条件函数。

点击原版“台词”按钮播放当前技能语音，再次点击轮换下一句，有台词文本时显示在说明下方。沿用游戏的音频解析器，支持武将与替代皮肤的语音映射及扩展音频路径，遵守技能语音开关和音量设置。试听只在本机播放，不发动技能，不广播或写入录像；切换技能、皮肤、页签、返回或关闭都会停止试听。

皮肤栏读取 `characterSubstitute` 注册形象与原生 `get.skinPath` 目录内已安装的图片；没有额外皮肤时只显示经典形象，不生成虚假选项。点击缩略图会切换大图及列表画像，使用原生 `skin` 设置保存，保留其他武将皮肤和所有禁将设置；保存失败恢复原值。离线同步当前对局对应角色的外观，联机不修改当前房间角色。选中形象决定详情页技能语音使用的皮肤映射；文件型静态皮肤沿用该武将的默认语音。

长按武将约 0.6 秒切换禁用/启用，详情大图也支持长按。禁用武将变灰，仍可查看详情或恢复启用。滑动、移出、关闭界面会取消未完成的长按；长按松手不会误进详情。电脑也可右键切换。

设置使用原生当前模式的 `<模式>_banned`，同步离线运行时的禁将列表；联机保存为 `connect_<模式>_banned`，供以后建房使用，不改变当前房间规则。保留其他模式及其他武将的设置，不移除当前对局中的角色。原生异步保存完成后更新界面；保存接口报告失败时恢复原值。

普通武将包和新版扩展武将包共用离线 `characters` 启用列表、联机 `connect_characters` 关闭列表；旧式 `mode_extension_` 武将包沿用 `extension_<扩展名>_characters_enable`。每次打开读取最新设置，保存后同时刷新已创建的原生设置页，反向在设置页修改后重新打开也会同步。整包加载状态在重启后应用，不卸载当前对局角色或技能。

离线打开界面暂停游戏，关闭后只恢复由本界面发起的暂停；联机不暂停。Esc 返回列表或关闭，Tab 在界面控件内切换。横屏并排显示详情，手机竖屏上下排列。

界面复用本机《三国杀》APK 的分类标签、返回箭头、搜索图标、技能标签、分包分隔条、详情页签、主动/被动标识、台词按钮、皮肤边框和背景，原图及来源记录位于 `assets/character-browser/`。画像、名字、技能与生平均读取无名杀本机已注册的数据，不依赖联网。

武将牌与开局选将共用 `src/ui/selectionPlayer.js` 和 `src/styles/selection-player.css`。直接复制当前对局武将牌的纯外观节点，沿用当前主题及边框等级的龙框、势力栏、竖排名字和体力勾玉。开局选将计算牌宽、牌高和缩放时，将这组实际数值留在当前游戏会话中；武将列表与详情原样取用并同比缩放，包含 HH 优化的武将宽度设置，不另设固定比例。旧对局没有记录时读取当前武将牌的实际尺寸。列表和详情不创建换将按钮。势力仍由游戏原有的势力渲染器处理，保留扩展势力和图片设置。

外观复制不调用 `player.init`，不复制玩家事件、技能或动态皮肤实例。体力按浏览武将本身的数据重建；没有对局模板时以相同的玩家外观结构显示。详情给龙头预留顶部空间；切换分类、详情或关闭时释放卡片的尺寸观察器。

详情尺寸回归覆盖带游戏缩放及外观额外缩放的情况，检查真实宽度匹配、比例保持、随可用高度变化而放大、横竖屏切换及左侧区域观察器清理。

验证覆盖扩展分类、搜索、原生模式禁将键及运行时列表、异步保存与失败回退、长按/滑动冲突、详情切换、暂停清理、分批加载、六套实际菜单入口和十九张界面资源哈希。新增整包及分包配置、离线/联机差异、设置页缓存刷新及调用本机原生设置处理器的交叉验证。另验证纯外观复制不修改模板、沿用势力渲染器、体力与大体力计数、卡片尺寸联动及观察器清理，以及详情技能标识、文件和注册皮肤、异步换肤保存与回退、语音皮肤映射、轮播、静音及清理。独立浏览器预览加载实际玩家样式表，检查横竖屏、金龙框与勾玉、无换将按钮、真实长按、分包开关、整包关闭的半透明显示，以及大图、详情面板、换肤与保存、真实技能音频播放；预览使用测试武将和皮肤数据，未进行实际对局目测。

# 斗地主座位布局

自己固定在右下角。地主视角的三号位农民在左上、二号位农民在右上；二号位农民视角的地主在上方、队友在右侧；三号位农民视角的地主在上方、队友在左侧。

位置逻辑来自 `E:/AI/sanguosha/sanguosha2/work/main.js` 的 `bMt.layoutSeatUi`，斗地主 2023 的农民分支按 `SelfSeat.FixedViewId` 区分二、三号位。原版基准为武将宽 174、上边距 15、侧座纵坐标 169、右边距 20，上排间隔按可用宽度限制在 14–100。左侧队友旁预留 47，上方地主相应右移 23.5。扩展按当前武将宽度换算这些坐标，保留独立高度和各主题外观。

座次从 `game.zhu` 沿 `nextSeat` 读取，包含阵亡角色；重连尚未建立物理座位链时使用原生 `data-position`。不用会忽略阵亡或离场角色的距离计算，也不修改原生座位编号、出牌顺序和点击节点。身份、座位及控制视角改变后刷新布局，并使飞牌动画的位置缓存失效。其它模式沿用原布局。

验证包含座位链、阵亡、重连回退、模式清理和动画缓存测试；浏览器执行原版函数，对照六种主题、三种窗口宽度、三种牌宽和三种视角共 162 组坐标。另在真实斗地主开局完成选将后，通过原生切换玩家验证三种视角及飞牌缓存，未出现脚本异常。

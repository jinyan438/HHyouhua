# 原版装备栏

资源来自 `E:/AI/sanguosha/extract/unity/sprite/assets/res/picture/game/seat/`，逐文件复制到 `assets/equipment/`，未修改图像。来源、SHA-256 和原版绘制类记录在该目录的 `sources.json`。

- 底图：`new_equip_card_bg_new.png`，140×30。
- 武器、防具、防御坐骑、进攻坐骑、宝物：`new_equip_type_3_new` 至 `new_equip_type_7_new`。
- 花色及点数：`other_equip_*_new`，黑色牌采用原版黑底白描边，红色牌采用原版红色字形。
- 装备名与范围：复用 `assets/general-font/FZLBGBK.woff2`，常规字重 400、颜色 `#FFF7F7`。

底图在装备栏的左、右两侧各延伸 2px；双马半栏的中间接缝不重复延伸，独立装备栏的空槽共用外侧延伸量。

原版 `sanguosha2/work/main.js` 的 `fns`（`EquipCardUi`）将图标、花色、点数、名称的横坐标设为 3、22、38、60，图标大小 20，名称字号 22。本扩展按这些比例适配已有装备栏宽度；独立装备栏行高 27px，武将牌中的装备条按栏宽缩放，长名称使用剩余宽度。武器显示自身范围，坐骑显示实际距离修正。

武将牌内的装备区移植 `AMt.LayoutEquipCards`、`fns.UpdateCardFace` 和 `xUt.updateUI` 的固定四行布局，原版整栏宽 146、行高 30。武器第一行、防具第二行、防御坐骑第三行、宝物第四行，缺少装备时保留空位。进攻坐骑优先占用空闲且可用的防御坐骑位，否则占用空闲且可用的宝物位；两处都不能使用时放在第三行右半边。因此没有防御坐骑时，即使有宝物，单张进攻坐骑仍可占满第三行。

两种坐骑位和宝物位均被装备、废除或技能占用时，坐骑宽度改为 73，第三行左侧为防御坐骑、右侧为进攻坐骑。半栏省略坐骑名称，保留图标、花色、点数及距离，距离的符号和数字按原版分别定位。废除栏按 `xUt` 保留固定行，显示对应图标及“废除”，坐骑废除时保留 ±1；宝物被占用时废除坐骑也使用半栏。原生技能占位保留完整技能文字，参与占位判断；普通隐藏的 `empty_equipN` 空槽不算占用。

恢复、拆除、置入、技能占位变化和重连均依据当前装备重新排布。布局只调整真实装备节点的位置，不移走、复制或重排真实节点；双马保持各自原生点击、选牌及结算功能。转换装备保留名称方括号，完整手牌、出牌、牌堆及装备移动副本继续使用完整牌面。无名杀特有的扩展同类装备位和特殊装备在对应行内分配可点击区域，合并坐骑仍占满第三行。独立装备面板继续使用完整名称及原有槽位。

装备区同时监听栏内节点、文字和状态类变化。原生广播、重连及其它后续更新直接重写 `name2` 时，也会依据真实牌名、花色和点数重建图标；完整且未变的节点不再重写，避免观察器触发自身循环。每个装备区只注册一个观察器，保留原生占位数据和技能文字。

装备条保持 `opacity: 1`，黑色半透明效果由原版底图自身提供。原生出牌选择状态会把不可选牌的 `name2` 降至 0.6，因此装备条需要覆盖该通用样式，避免连续装备后返回选择状态时整条文字和底图再次变淡。

布局来源、原文件 SHA-256 与函数哈希见 `assets/equipment/layout-source.json`；对应函数快照保存在 `tests/fixtures/source-equipment-layout.json`。回归测试直接执行原版函数，对照 1024 种装备、废除、不可用组合的实际牌布局，以及 243 种装备、废除组合的废除栏位置和宽度。

开发服务器 Vite 会把 `new URL("../../assets/equipment/", import.meta.url)` 的目录参数转换成不含末尾斜杠的路径。拼接文件名前必须补齐斜杠，否则会请求不存在的 `assets/equipmentnew_equip_type_4_new.png` 等地址。回归检查须导入 `127.0.0.1:8080` 实际转换后的模块，验证图标、花色和点数图片的响应及加载结果。

整套入栏逻辑来自 `sanguosha2/work/main.js` 的身份局实现：`GMt.onCreateCardMotion → onFirstMotionComplete → showACardMotion → onMotionComplete → AMt.setAEquipCardActive → LayoutEquipCards → Yki.Run`。`Seat_Equipment / startEquipCardMotion` 通过 `SHOW_A_CARD_MOTION` 传递目标坐标、缩小比例 0.1 和结束回调。原版使用 Laya 显示对象；扩展移植相同阶段、缓动及回调顺序，显示坐标按 HH 武将牌与实际装备栏换算。

`VUt` 的默认参数：普通玩家先用 200ms 的 `sineOut` 放大至 1.2 倍并抬升 15 个原版单位，再用 200ms 线性缩到 0.1；本地玩家两个阶段均为 267ms，抬升 30。放大时 x、y 各补偿牌宽、牌高的 0.1。原版基准武将框为 174×232、牌面 126×174；Web Animations 对原版正弦进度采样，移动与缩放使用同一进度。1500ms 看门狗对应客户端的兜底清理。来源哈希、调用链及参数记录在 `assets/equipment/motion-source.json`。

牌面完成缩小后才显示装备条并横向滑入：原版 `M_EQUIP_SIZE.width` 为 146，从 `seatX - 146` 移到 `seatX + 27`，距离 173，耗时 300ms、线性移动。半栏也从同一整栏左侧起点进入，右半栏的行内偏移计入滑入距离；动画裁剪范围覆盖整行，避免在进入最终半栏前一直不可见。缩小落点按原版尚未滑入的装备条右边缘计算，半栏落点位于 `seatX - 73`，与最终左右半栏的位置无关。扩展按实际栏宽换算，底图资源自身的 140px 宽度不作为布局常量。

关闭“装备牌移动优化”时直接滑入。已有装备、同栏排序及文字刷新不重播；转移至另一玩家重新滑入，移走、替换和对局结束会取消等待及动画，恢复原有样式。只移动视觉内容，选牌、点击及原生结算不等待动画。

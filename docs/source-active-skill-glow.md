# 原版主动技能按钮光效

使用 `E:\AI\sanguosha` 中 Unity 客户端的 `Assets/Res/Effect/FxEffect/fx_UI_AnNIu_ZhuDong.prefab`，包括金色发光按钮与内部闪烁星点。

`assets/active-skill-glow/` 保存原始 `fx_UI_AnNIu_ZhuDong_00` 边框、`FX_jjc_lizi` 粒子贴图以及转换后的动画。`sources.json` 记录 bundle、资源路径、SHA-256、可见框位置和原版粒子参数。星点沿用每秒 10 个、寿命 1 秒、先亮后暗的节奏；边框由每秒 2 个、寿命 1 秒的重叠光效形成呼吸。二维位置与漂移转换成 20 帧、1 秒循环的精灵图，使用原始星点贴图，不添加文字或符号代替粒子。

`tools/bake-active-skill-glow.py` 可用 Pillow、NumPy 重新生成精灵图。原始星点使用加法混合，转换时将黑色零发光区域变为透明，避免出现黑色方块。

各主题仍用原有逻辑更新 `usable` 和 `select`。只给定义含 `enable` 的主动技能添加光效标识，可用或选中时显示边框及星点；不可用、已用限定技或禁用按钮关闭。可选择的被动技仍能正常操作，不会误用主动技能光效。共享逻辑及手杀、新杀的独立更新路径均接入，覆盖普通技能、额外技能和左右手布局。

# AI 思考节奏

在 HH 优化设置中开启“启用AI思考延迟”。新安装默认开启，已有开关状态及思考时长设置继续保留。

每次实际出牌、技能选择、杀闪响应分别模拟观察和操作停顿。使用最终选定的牌、技能、目标和公开场面判断节奏，不改变原生 AI 的选牌、目标或收益计算，也不额外运行这些决策回调。

默认设置下：

- 普通主动用牌通常约 0.8～2.6 秒，首次规划、复杂选择及关键取舍更久。
- 普通杀闪响应约 0.5～2 秒，不再走原先约 150～570 毫秒的快速确认路径。
- 无中生有、自己吃桃、装备空栏等顺手用牌约 0.5～1.6 秒，仍为每张牌保留独立停顿。
- 唯一选项、简单确认、结束出牌阶段及已预思考的自救保留短点击节奏；没有可用响应牌时直接继续，不让所有角色逐个空等。

每个角色保留自己的速度、果断及风险特征，每次决策再独立取样。连招只偶尔缩短操作时间，几张之后恢复观察，不按连招次数持续压缩；同阶段得牌（包括手牌总数没变）、体力、护甲、装备、判定区变化和响应打断后重新规划。普通复杂操作平滑接近配置上限，减少大量操作都被截成相同时长的情况；只有关键取舍有 6% 概率追加长考。

“最短思考时间”控制普通思考下限。顺手用牌、杀闪及简单确认不因提高此下限而变成十秒长考，但均遵守普通最长时间；最短和最长设为 0 时取消额外等待。原有长考最多额外 1500 毫秒的设置不变。

这些停顿使用独立计时器，在最终结果提交到出牌、响应之前等待一次；同一次出牌的技能子选择与外层包装不会重复计算。新的出牌、独立技能选择和后续响应单独计时。结算优化继续跳过系统流程的重复展示等待，不缩短思考计时，也不更改“中”档、HH 倍率或动画时长。进度条和思考文字跟随实际等待时长清理。

关闭思考开关后直接沿用本体选择流程。真人手动操作、联机、录像、游戏结束及因操作超时托管的本地角色不增加模拟思考等待。

验证包含原生 `chooseToUse / chooseToRespond` 的出牌结果与顺序、等待完成前不提交操作、连续出牌及杀闪逐次计时、得牌和公开场面变化、角色与逐次分布、上下限及零时长、开关、子选择去重、暂停提示清理和结算优化共存。另用本体 `GameEvent / ContentCompiler / PauseManager` 在独立浏览器中执行原生选择内容，核对真实计时和不同 HH 倍率下的思考一致性；未运行完整 AI 对局。

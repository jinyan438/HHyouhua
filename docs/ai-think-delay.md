# AI 思考节奏

在 HH 优化设置中开启“启用AI思考延迟”。新安装默认开启，已有开关状态、思考上下限和提示设置继续保留。

每次实际出牌、杀闪响应、发动技能、选牌选目标、弃牌、给牌、移牌、选数、选技能和选项确认分别模拟观察与思考。没有可响应的杀、闪、桃或选择放弃响应时也先停顿再交还结果。唯一选项、代选、预选牌、频繁技能、强制弃光和结束出牌阶段也有独立停顿。无懈可击沿用原来的节奏，无牌或放弃时继续快速跳过。

默认节奏下，简单确认通常约 0.9～2 秒，顺手用牌和杀闪通常约 1～2.6 秒，普通主动用牌保留约 1.2 秒起的规划时间。首次规划、复杂取舍和公开场面变化会适当增加等待；关键取舍仍有 6% 概率长考，最多额外 1500ms。使用上下限设置时，各种实际选择都遵守设置，最短和最长均设为 0 时取消等待。

角色有不同的速度、果断和风险特征，每次决策独立取样。连招只偶尔顺手接续，几张后重新观察；同阶段得牌（包括手牌总数没变）、体力、护甲、装备、判定区变化和响应打断后重新规划。取样先确定有效范围，减少大量简单操作都被截到同一最短时长的情况。

数组步骤同时识别 event.result、第四参数 result 及步骤返回值，在真实结果产生后、操作提交前等待。结果只在独立 WeakMap 中记录，不提前覆盖引擎字段；提前 finish 的选择也在当前步骤退出前完成等待。不插入新步骤，保留 goto / redo / this / 第四参数 / 返回值。旧式步骤使用本体编译器的已编译步骤体和相同的沙盒依赖；已编译数组和异步函数也接入。其他扩展的不透明编译结果在进入内容前等待，不改变其执行体。竞技场初始化时重接稍后替换的选择内容，以每个函数为单位去重，避免漏接或叠加。

支持 cards / targets / links / moved / numbers / skill 等结果形状。选到带按钮的技能也保留选技能时的停顿；实际出牌尚待转换选择时再处理最终结果。同一次出牌的转换子选择与外层包装共同计时，结算中的独立技能选择和后续响应分别计时。濒死预思考后沿用已完成的等待。

本体开启 skip_shan 时，无闪的杀会直接跳过整个 chooseToUse。扩展在 shaHit 的最早阶段为这次未经过选择的普通响应补充相同节奏的等待，结束后再进入命中效果和伤害；不修改跳过询问的设置，也不重新探测手牌或运行 AI。每次已完成的出闪选择按当前 shanRequired 记录，已思考的失败响应不重复等待；需要两闪时，先出一闪后第二张无闪仍是新的响应。强命中及技能自动闪避沿用原流程。思考进度条和提示与这段补充等待同步。

借刀杀人在无杀时同样可能完全跳过询问，直接交出武器。扩展在 jiedaoBegin 的其他触发处理完成后，先让被借刀的 AI 观察并取舍，再运行原版内容；无杀交武器、有杀但放弃及实际出杀共用一次思考。原版的 hasSha 检查仍只执行一次，内层 chooseToUse 和转换子选择不重复等待；借刀引发的杀进入实际 useCard 后，另一角色的杀闪响应仍单独计时。强制命中、无合法后续目标、真人、联机及关闭设置沿用原流程。

原生 chooseButton 在同一步算出 AI 结果并立即调用同步 callback；chooseDrawRecover、chooseToEnable 和 chooseToDisable 也可能直接执行唯一效果。此类入口改为执行前观察，并与内部的子选择共用停顿。装备栏的选择按 source 对应的真正操作者计时，受影响的武将不会代替其思考。同步回调的参数、返回值及调用次数保持原样。chooseUseTarget 接入返回值结果，在技能直接使用指定牌、自动确认目标时，也先思考再 useCard。

本体选择入口检查如下。多人入口保留原版选择、结算和展示顺序，固定结果及纯规则效果不额外制造选择。

| 范围 | 思考入口 |
| --- | --- |
| 主动用牌、杀闪、借刀、濒死求桃 | chooseToUse / chooseToRespond，加上无闪与借刀的跳过分支、逐人求桃等待 |
| 技能直接用牌、自动确认目标 | chooseUseTarget，读取步骤返回结果，子确认与外层去重 |
| 选牌、选目标、按钮、选项、数值及技能 | 各原生选择入口；按钮的同步回调执行前等待 |
| 弃牌、给牌、拆牌和顺牌 | chooseToDiscard / chooseToGive / choosePlayerCard / discardPlayerCard / gainPlayerCard |
| 拼点、多人拼点、议事 | 原生 chooseCardOL 逐人委托 chooseCard，每个实际选牌者分别等待 |
| 对策、猜拳、协力选择 | 原生 chooseButton / chooseButtonOL 的实际选择，不对结果展示再次等待 |
| 观星、移牌及排序 | 原生 chooseToMove / chooseToMove_new，不改变移动结果或动画 |
| 摸牌或回血、恢复或废除装备栏 | 唯一操作也在效果前等待；按真正的选择来源计时 |

思考使用独立计时器，进度条和提示与真实等待同步。保持“中”档、HH 倍率和动画参数，不改原生 AI 的选牌、选目标或收益计算，也不额外执行这些决策回调。普通无牌响应与有牌响应使用同一时长分布，默认约 1～2.6 秒，遵守思考上下限；摸牌、伤害及锁定技能等系统结算不增加模拟选择。托管和超时接管的角色与其他 AI 一致思考。真人手动操作、联机、录像和游戏结束沿用原流程。

验证覆盖默认及上下限、不同节奏分布、简单操作逐次等待、无牌响应及提前结束选择的结果阻塞、无闪快速跳过、两闪的后续响应、借刀三种结果、指定牌直接使用、同步回调、唯一效果及装备栏操作者、多人选牌、给牌移牌选数选技能结果、子选择去重、关闭功能、联机真人隔离、旧式及编译代码、稍后替换和重复安装。另在独立浏览器的沙盒中通过本体 GameEvent / ContentCompiler / PauseManager、真实玩家节点、全局技能注册及标准卡牌触发链，核对交武器、实际出杀、直接用牌、回调、摸牌及装备栏效果发生前的真实计时；同时检查伤害前等待、无懈例外及倍率独立性。未逐个运行所有第三方技能或完整 AI 对局。

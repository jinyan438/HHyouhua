# AI 思考节奏

在 HH 优化设置中开启“启用AI思考延迟”。新安装默认开启，已有开关状态、思考上下限和提示设置继续保留。

每次实际出牌、杀闪响应、发动技能、选牌选目标、弃牌、给牌、移牌、选数、选技能和选项确认分别模拟观察与思考。唯一选项、代选、预选牌、频繁技能、强制弃光和结束出牌阶段也有独立停顿。

默认节奏下，简单确认通常约 0.9～2 秒，顺手用牌和杀闪通常约 1～2.6 秒，普通主动用牌保留约 1.2 秒起的规划时间。首次规划、复杂取舍和公开场面变化会适当增加等待；关键取舍仍有 6% 概率长考，最多额外 1500ms。使用上下限设置时，各种实际选择都遵守设置，最短和最长均设为 0 时取消等待。

角色有不同的速度、果断和风险特征，每次决策独立取样。连招只偶尔顺手接续，几张后重新观察；同阶段得牌（包括手牌总数没变）、体力、护甲、装备、判定区变化和响应打断后重新规划。取样先确定有效范围，减少大量简单操作都被截到同一最短时长的情况。

数组步骤在真实结果产生后、操作提交前等待，不插入新步骤，保留 goto / redo / this / 第四参数 / 返回值。旧式步骤使用本体编译器的已编译步骤体和相同的沙盒依赖；已编译数组和异步函数也接入。其他扩展的不透明编译结果在进入内容前等待，不改变其执行体。竞技场初始化时重接稍后替换的选择内容，以每个函数为单位去重，避免漏接或叠加。

支持 cards / targets / links / moved / numbers / skill 等结果形状。选到带按钮的技能也保留选技能时的停顿；实际出牌尚待转换选择时再处理最终结果。同一次出牌的转换子选择与外层包装共同计时，结算中的独立技能选择和后续响应分别计时。濒死预思考后沿用已完成的等待。

思考使用独立计时器，进度条和提示与真实等待同步。保持“中”档、HH 倍率和动画参数，不改原生 AI 的选牌、选目标或收益计算，也不额外执行这些决策回调。摸牌、伤害及锁定技能等系统结算不增加模拟选择；没有普通响应牌时直接继续。托管和超时接管的角色与其他 AI 一致思考。真人手动操作、联机、录像和游戏结束沿用原流程。

验证覆盖默认及上下限、不同节奏分布、简单操作逐次等待、真实结果提交前阻塞、给牌移牌选数选技能结果、子选择去重、关闭功能、联机真人隔离、旧式及编译代码、稍后替换和重复安装。另在独立浏览器通过本体 GameEvent / ContentCompiler / PauseManager 执行原生选择和编译步骤，核对真实计时、动作顺序及倍率独立性；未运行完整 AI 对局。

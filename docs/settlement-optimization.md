# 结算速度优化

“HH优化 → 游戏速度”下方的“优化结算速度”默认开启，切换立即生效并保存。该开关不写入速度档、HH 倍率、动画时长或 AI 思考配置。

原版来源为 `E:/AI/sanguosha/sanguosha2/work/main.js`，SHA-256 为 `9da2e7f5f71cd6dbd786d22015f2630661180a22eeb1195da47f26f737b9f078`。Rk.Handler / NMt / Zv 处理移牌视觉消息，xvi.invalidateLayoutHandCardFlag 合并同帧布局，VUt 管理特效停顿配置。资源中没有原版服务端的技能结算器，本扩展继续使用无名杀原生规则、触发器及事件队列。

优化范围：

- 同一帧、同一上下文的手牌和弃牌布局各执行一次；其他回调、不同上下文和事件顺序保留。
- 普通得牌保留原顺序入区、打标记、广播和显示，使用本次动画的实际到达通知替代固定的 min(400 × HH倍率, 400) + 66ms 暂停。自己手牌 300ms 完成后交还实体牌，其他玩家完成 700ms 飞行后继续，后续停留及淡出独立播放。
- 原生 gaincardMultiple 包装在调用期间标记已有到达管理，仅在这个作用域内移除重复的默认及 500/700ms 固定移牌等待；包装结束前共同等待本批接收者真正到达，并在成功、异常时清除标记。缺少或关闭到达管理时使用原等待。
- draw / gain / lose / loseAsync / discard 等已知数据事件明确禁用动画时，可跳过无参数的重复等待。每约 8ms 或 64 次优化操作通过本体 PauseManager 交还界面线程。

卡牌、主动技能、响应、伤害、回血、体力变化、横置、翻面、装备、判定、拼点、死亡及未知卡牌、技能的默认展示等待全部交给本体。useCard / useSkill 的多目标 delayx(0.5) 间隔保留。数值延迟、自定义动画函数、sync_speed 转场监听、手动暂停、选择及联机录像均沿用原流程。不会通过广播、修改速度倍率、提高播放速率或释放其他模块的暂停来提速。

这次收紧范围后，实际提升取决于数据移牌和重复布局所占比例；包含动画展示的技能会保留相应时长。早期跳过普通卡牌/技能展示等待得到的倍数基准不再代表当前行为。

动画到达从浏览器实际开始播放起计时，自己手牌使用完成回调，飞牌检查实际动画时间。手动点击、移走、失败、看门狗和对局结束会释放到达通知并清理样式，避免卡死或隐藏实体牌。没有替换 game.pause / resume 或提前取消已有暂停。

具体动画来源、检查方式和覆盖范围见 [动画检查记录](animation-settlement-isolation.md)。

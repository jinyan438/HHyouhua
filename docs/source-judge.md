# 原版判定动画

通用判定、装备判定、延时锦囊及技能判定共用原版 `panding` 动画。判定牌进入中央牌区时显示原版“即将判定”标记；最终生效播放 `play`，失效播放 `play2`。仅显示原版素材自带的标记，不额外添加牌底文字或角色结果弹字。结果从出现起保留 1500ms，再用 300ms 淡出，之后继续结算回调。

资源来自 `E:/AI/sanguosha/sanguosha2/yoka.game_g_android_4.0.2.apk` 的 `/res/assets/animate/game/fight/panding.*` 和卡牌图集。原始 Spine 4.0.56 骨骼、贴图及三张状态图保存在 `assets/judge-effects/`，来源路径、缓存键、裁剪坐标、文件散列和原版方法记录于 `sources.json`。逻辑依据 `sanguosha2/work/main.js` 的 `GMt.PlayJudgeAnimation`、`oCs.PlayJudgeAnimate`、`qEs.PlayJudgeAnimate` 及 `q_s.UpdateJudgeResultAnim`。

`sourceJudge.js` 在原生 `judgeFixing` 触发中等待结果动画，不替换判定计算或牌的移动流程。优先按技能的 `judge2` 判断效果是否生效，避免将乐不思蜀等延时锦囊的“不利结果”显示成失效；没有 `judge2` 时使用判定值和已知延时锦囊的方向。中性结果不播放成功或失败动画。

鬼才等改判会在原槽位换成最终判定牌，只播放最终结果。连续判定沿用 [中央牌区](source-reveal.md)，已显示的牌保留到本次技能结束；普通判定在该次判定结束后清理。屯田入田、洛神得牌等原生回调在结果动画后继续执行。

效果跟随实际牌面中心及缩放，复用独立的 Spine 4 运行库，不覆盖动态皮肤的运行库。关闭游戏动画时不增加等待；资源或 WebGL 不可用时保留原版静态结果标记。切出页面或游戏结束时解除等待并清理效果。联机、录像和棋盘模式沿用原展示。

验证包含资源散列、两套真实骨骼时间轴、结果方向、原版停留与淡出时长、改判、关闭动画及异常清理。完整开局检查覆盖身份与斗地主；实际判定流程覆盖通用判定、八卦阵、乐不思蜀、兵粮寸断、闪电、屯田、鬼才改判及洛神连续判定。

# 全屏选将

扩展的“全屏选将”开关同时控制本地标准身份、明忠及斗地主，默认开启，重启生效。保存键仍为 `identity_fullscreen`，沿用原设置。

斗地主直接使用身份局的选将对话框、开局武将外观组件、牌面实际宽高、技能面板和确认交互。候选武将在中央排列；左上角显示三人座位，地主红色、农民绿色；底部显示当前的地主/农民身份。单击武将查看技能，再点同一张牌确认，双将按模式要求选满后提交。

换将按钮及同名版本提示的大小、边角偏移和贴图均以武将牌宽度为基准，随窗口与游戏缩放同步调整，保持相对牌面的比例。

勾玉按实时宽度设置确定左侧局部坐标，与牌面一起缩放；窗口拉伸和修改武将宽度后都会自动补偿位置，拉伸后再换将也使用相同锚点。预览中的血条关闭位置过渡动画。该外观组件同时用于武将列表和详情。

选将中的血条容器单独保留原主题的 `content-box` 计算，避免全屏界面的通用 `border-box` 规则压缩带边框的容器、把勾玉向画像中挤偏。

候选武将来自原生 `chooseCharacter` / `chooseButton`，不重新抽取或初始化角色，不改变原生叫地主、身份分配、AI 选将及后续规则。原生候选多于一行时可以滚动查看。没有胜率数据时不添加“最高胜率”标签。

| 斗地主玩法 | 保留的原生规则 |
| --- | --- |
| 标准 | 按地主/农民的候选数设置显示，保留双将；随机换将读取模式提供的合法候选池，同名版本仍校验禁将。 |
| 开黑 | 自己和队友的候选区分别保留，只能选择原生允许的自己的候选。 |
| 欢乐 | 保留叫地主及各玩家的固定候选分配。 |
| 兵临城下 | 保留叫地主、城池技能及队友候选区，只能选择分配给自己的候选。 |
| 智斗（本地 `online` 子模式） | 保留叫地主、20 张底牌及地主双将、农民单将要求，底牌不能作为武将选择。 |

固定候选玩法不显示随机换将或同名版本入口，避免越过该玩法的原生分配限制。联机房间、乱斗、自选全武将弹窗和叫地主控制弹窗继续使用原界面。

关闭或删除选将对话框时，解除监听、取消计时并恢复原生控制栏。身份局继续使用原身份牌展示动画；斗地主直接显示已分配的身份，不播放主公/反贼身份牌。

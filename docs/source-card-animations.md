# 标准与军争卡牌动画

启用 HH优化后自动应用卡牌动画，不增加设置项。沿用无名杀的“动画效果”开关。标准包 32 种实体牌、军争包 10 种实体牌的名单直接与游戏 `card/standard.js`、`card/extra.js` 的实际牌表核对；火杀、雷杀、冰杀作为杀的属性变体，不重复计入 42 种牌。普通杀、雷杀、火杀和闪已恢复本次替换前的出牌、响应特效，普通杀仍区分红杀、黑杀，并撤掉这些杀新增的命中叠加效果。过河拆桥、万箭齐发关闭新旧特效；其他卡牌按下述时机与位置播放。

从用户本地三国杀客户端导出 63 套 Spine 4.0.56 骨骼、70 张图集页面，共 196 个原始文件，约 51 MB。`assets/card-effects/sources.json` 保留每个文件的来源路径、缓存键、大小与 SHA-256，原始骨骼、图集和贴图未改动。映射见 `src/effects/sourceCardAssets.js`。

出牌和响应入口接在 `lib.animate.card`，出牌区的实体牌、虚拟牌共用事件去重；转换牌压制原生弹字时也可播放。乐不思蜀、兵粮寸断、闪电在使用、响应及进入判定区时不播放特效，仅在原有判定生效分支中通过 `lib.animate.skill` 播放；判定未生效或闪电转移时不播放。乐不思蜀生效时的关窗动画缩至原来的 80%。兵粮寸断在长坂模式判定生效时也播放，仍保留该模式原有处理。

非延时锦囊在屏幕中央出牌区的实际用牌位置播放，每次使用只播放一次，多目标不重复播放。特效跟随卡牌节点的布局变化；没有可用卡牌节点时使用牌桌中央，节点移除后保留最后位置至动画结束。火攻大小为之前的 80%，决斗和无懈可击以出牌位置的基础尺寸放大至 160%；全局锦囊保留画面比例的尺寸，以实际用牌位置为中心。

顺手牵羊在出牌时不播放，仅在其直接调用的 `gainPlayerCard` 实际产生 `gainAfter` 且获得牌非空后播放，并对同一次获得事件去重。选择期间、无可获得牌、被抵消以及其他技能的嵌套获得牌事件不触发。联机广播只传玩家和卡牌，在各客户端取对应出牌位置。装备发动替换原有 `lib.animate.skill` 映射，直接装备通过 `equipAfter` 补充播放，并避免与正常使用装备重复；冰杀命中在实际 `damageEnd` 后播放效果。

顺手牵羊触发器的 `content` 必须保留为异步函数：引擎的 `StepCompiler` 会重新构造普通函数，丢失外层去重集合并导致 `shownSteals is not defined`。2.0.5 改走保留闭包的 `AsyncCompiler`；回归检查使用游戏实际的编译器、隔离函数构造器和步骤状态逻辑执行三个卡牌触发器。

卡牌伤害、距离、装备能力、响应规则和延时锦囊判定沿用原规则，没有覆盖卡牌的 `content`、`effect`、`onEquip` 或 `onLose`。

卡牌音效共 5 段：顺手牵羊的羊叫声，客户端 `getDefaultSoundUrl` 对应的武器 `wuqi`、防具 `fangju`、坐骑 `ma` 装备音效，以及木牛流马入场音效，覆盖标准与军争的 23 张装备牌。依据本地客户端代码中的资源路径从原站补齐缓存缺少的声音，原始 OGG 存放在资源工作区，扩展随附兼容网页与手机播放的 MP3；`assets/card-audio/sources.json` 记录来源、原始及转换后的哈希、时长。原始映射见 `src/audio/sourceCardAudioAssets.js`。

顺手牵羊使用原客户端 `shunshouHit` 的羊叫声 `3d_4_spell2`，在实际顺走牌后与动画同时播放，出牌时不播放该音效。装备在 `equipAfter` 播放各自的入槽音效，屏蔽同次装备的旧通用音效并对重复触发去重；卡牌名称播报及技能发动语音保留。音效沿用默认开启的“启用音频替换”，遵守游戏全局音效开关和音量，并独立于画面特效开关。未映射的其他包装备及加载失败的装备声音回退到原音效。

动画复用模块内的 Spine 4.0 运行库，与原有动态皮肤的 `window.spine` 隔离。多个玩家或多张牌可同时播放，每个实例有独立骨骼姿态；显示层不接收点击，并随角色位置和界面尺寸更新。缓存最多保留 6 套、约 16M 图集像素，正在播放的资源暂不驱逐；播放结束、断开角色、切到后台及游戏结束时清理实例。文件或 WebGL 加载失败时恢复原有显示。已被替换的旧卡牌效果不再参与后台批量预加载，仍可按需作为降级资源使用。

验证包括 42 种牌与实际牌表一致性、196 个原始文件哈希、63 段时间轴逐帧采样、普通牌和虚拟牌去重、响应、多目标、实际出牌节点跟随、火攻与决斗尺寸、过河与万箭禁用、原生顺手牵羊内容及获得牌时机、直接装备、装备发动、属性命中、同屏叠加、资源回收与降级。原有连斩的检查继续通过。使用已安装渲染器的几何结果生成过静态预览；尚未完成真实浏览器的游戏内视觉验证。

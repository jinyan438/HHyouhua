# 原版卡牌

标准包 32 种、军争包 10 种实体牌，以及火杀、雷杀、冰杀使用本机 `E:/AI/sanguosha/sanguosha2/yoka.game_g_android_4.0.2.apk` 内 Laya 客户端 `res/assets/cards/cards.png` 图集的 PNG 版本。卡图、4 种花色、红黑各 13 种点数共 75 个文件按图集坐标无损切片到 `assets/original-cards/`，保留原始像素、透明通道与尺寸。来源 APK、图集及输出文件的 SHA-256、切片名称和坐标记录在 `sources.json`；使用 `python tools/import-original-cards.py <APK路径>` 可重新导入。实体牌仍使用引擎自身的花色与点数，不改牌堆构成；其它扩展牌继续使用原有皮肤。

按原客户端 `Rns.layout`，数字位于 (5,7)，尺寸 18×22；花色位于 (2,30)，尺寸 24×20。图片保留透明通道，A/J/Q/K 使用原字形。复制牌、出牌、响应和判定沿用相同显示；临时花色点数也使用这组素材，未知数值保留文字回退，暗牌隐藏花色点数。

原始 PNG 自带圆角牌边与阴影，原版牌面禁用主题和 HH 额外添加的矩形 `box-shadow`，避免图片透明边缘外出现方框。

明牌的独立牌面层与牌面上的花色、点数分别使用 `blur(0.4px)` 轻度柔化，按 126×174 基础牌面的坐标计算，随手牌、中央牌及弹窗等比缩放。卡牌容器不加滤镜，装备栏、判定栏、选中框、技能标记及来源提示保持清晰；卡牌进入装备栏或判定栏时隐藏牌面层，移回手牌或复制展示时自动恢复。复制牌与临时花色点数沿用相同柔化，暗牌保留牌背原有显示。原始 PNG、花色点数位置和状态蒙版来源保持不变。

不可选、已使用等状态的暗色遮罩，以及底部来源提示，使用当前卡图的 alpha 作为 CSS 蒙版。四角与牌边按素材自身的抗锯齿轮廓显示，避免直角遮罩填满圆角外侧；复制牌继承同一轮廓，切换为非原版牌时清除蒙版来源。

牌面与蒙版共用按文档地址解析后的绝对素材 URL，兼容空素材前缀、子目录及本地文件启动，防止 CSS 自定义属性里的相对 URL 被解析到样式表目录而使遮罩透明。出牌来源的底部渐变半遮罩与“使用／打出”文字同步恢复，保留原来的高度与样式。五谷丰登已领取的牌沿用本体添加的领取者标记，显示同一层 40% 黑色遮罩；未领取的牌保持正常亮度。

基础牌面为原版 126×174。按原版移动端设计高度 750 等比适配，手牌高度占窗口的 174/750（0.232）；中央牌面使用原版 0.87 倍，即高度比例 0.20184。取消旧的 1 倍缩放上限，使大窗口也保持这个比例。固定使用原版比例，每次加载校正旧配置；手牌大小、中央大小、手牌折叠、卡牌美化、卡牌边框、旧OL替换、花色数字颜色、柔化、图片替换及偏移设置暂时从菜单停用。运行时也绕过旧图片注入、数字观察器和边框覆盖，避免已保存值或主题重新改变原版样式。

手牌按 `xvi.computeHandCard` 左对齐、正常零间隔，空间不足时在同一行均匀重叠；选牌展开和一一分牌继续使用原有流程。中央牌按 `GMt.layoutStackCardUis` 的 5 单位间隔、0.87 牌面缩放和溢出压缩公式排列。中央区域继续使用 HH 现有的可用宽度，旧牌在左、新牌在右。

原客户端方法快照保存在 `tests/fixtures/original-card-layout.json`。回归检查以快照执行结果对照布局公式，并核对实际标准/军争牌表覆盖、素材哈希、四种花色的 52 组点数和旧配置覆盖防护。

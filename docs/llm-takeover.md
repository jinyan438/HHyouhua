# 大模型接管

打开「扩展 → HH优化 → 大模型接管 → 连接与座位设置」，填写 OpenAI 兼容 API 地址和密钥，点击「拉取模型」后选择模型，也可直接填写模型名称。地址填写到 API 根路径，例如 `https://api.example.com/v1`；粘贴以 `/chat/completions` 或 `/models` 结尾的地址也会自动规范化。保存后开启「接管其他座位」。默认关闭。

DeepSeek 官方接口可填写 `https://api.deepseek.com`，使用该服务的有效 API 密钥。拉取期间按钮显示「正在拉取…」，结果或错误显示在模型区域；成功后使用原生下拉框选择模型，选择「手动填写」可编辑模型名称。安卓按钮直接响应触摸，弹窗内可正常输入和滚动。

此功能用于离线对局。玩家当前座位保持手动操作，包括玩家自己开启托管时；其他座位的实际选择交给模型。联机与录像沿用原生流程。无可选项、固定结果和锁定效果继续由游戏规则处理；拼点、议事、对策、猜拳、救桃、技能直接用牌及装备栏调整通过原生子选择接入。

「通用提示词」对所有接管座位生效。「座位」下的提示词分别保存，可以逐个切换编辑。每个角色独立保存本局可见记录和操作对话，其他座位不会接收到其提示词、模型决策或私下看牌记录。新对局和对局结束会清理上下文。「保留最近操作」只限制对话记忆的操作次数，设为 0 时不保留过去的对话；每次请求仍发送本局至今的可见牌局记录。

每次 API 请求都重新注入当前视角、完整可见牌局记录、场面、当前选择及规则资料：本座位与已经公开的主副将定义、武将文本、全部关联技能代码及说明、当前可用技能与卡牌资料。对方未公开的手牌、暗将、身份、私有存储、暗置判定牌和未知牌堆顺序不发送。通过原生知情者记录得知的牌可以进入该座位视角。暗牌按钮使用本次选择内的不透明编号，模型可以选择该编号，但无法读取对应暗牌。记录在事件发生时按视角保存，不直接上传全局录像或完整游戏对象。

模型通过 `game_action` 使用下列操作。返回纯 JSON 参数的模型也可使用同一接口。

| 操作 | 用途 |
| --- | --- |
| `inspect` | 获取刷新后的当前场面和可选项 |
| `skill` | 发动当前可用的主动技、转化技、重铸等原生技能入口 |
| `card` / `target` / `button` | 选择或取消选择牌、目标、按钮，保留先后顺序 |
| `control` / `bool` / `skill_choice` | 提交选项、是否发动、获得技能等选择 |
| `numbers` | 提交满足原生数值条件的组合 |
| `move` / `swap` | 观星、移牌及普通/分组排序，逐次检查 `filterMove` |
| `tap` | 为演奏提交点击时刻，按原生时间窗口和权重计算结果 |
| `confirm` | 检查条件后交给原生确认与后续结算 |
| `cancel` / `reset` | 放弃响应、结束出牌或退回选择 |

普通选择复用 `game.check`、技能备份/恢复和原生确认接口。转化技能的按钮、目标以及后续子选择继续由游戏生成，不允许模型执行任意 JavaScript、改写角色状态、修改规则或跳过费用。排序与选数检查原生限制；演奏按输入时刻计算得分，模型不能直接指定准确率。

请求默认 120 秒超时；每次选择最多 96 轮请求，非法操作会反馈给模型修正。失败时默认提示并让原生 AI 完成本次选择，也可设置为「暂停并询问」，选择重试、本次原生 AI 或关闭接管。修改连接设置、关闭接管或结束对局会中止进行中的请求，过期结果不会操作其他事件。设置窗口会显示最近一次连接错误。

密钥以密码输入框显示，保存在游戏本地配置中，不写入牌局记录、模型消息或错误提示。浏览器运行时，服务需允许游戏页面进行跨域请求。接口应支持 Chat Completions 的工具调用；当前请求不会静默截断规则代码或可见记录，因此应选择上下文容量足够的模型。

验证：`node --test apps/core/extension/HH优化/tests/llm-takeover.test.mjs`。测试使用模拟 API，执行本体选择、校验、点击处理及真实事件编译器，覆盖信息隔离、转化技、排序、座位上下文、超时、中止和失败回退。设置窗口另以原生游戏布局样式验证模型拉取、提示词切换和保存。

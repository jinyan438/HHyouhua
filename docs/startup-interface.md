# 启动界面美化

2.0.25 将缘伴随行的“启动界面美化”1.2.1 合并进 HH优化。视频、音乐、音效、字体和图片完整收录于 `assets/startup/`，不依赖原扩展目录，在线更新时一起校验和安装。原许可证保留于 `assets/startup/LICENSE`。

“扩展 → HH优化”提供启动美化开关、预览、背景视频、背景音乐和显示比例。默认启用，首次合并使用 `孙尚香.mp4`，之后保留用户在 HH优化 中选择的视频。支持六套背景视频、两段开场动画和八首背景音乐；网页无法读取目录时仍提供全部内置选项。

默认音乐为“原版大厅”，即原客户端 `MainBgmUrl` 指向的 `BackGroundMusic01`，约 154 秒。直接收录提取的 AAC/M4A 文件，未转码；来源和校验值见 `assets/startup/music/sources.json`。旧默认 Aira 一次性切换为原版大厅，已选择其他曲目的设置保留，迁移后主动选择 Aira 也会保留。

旧扩展从启用列表移除并停用，音乐选择及视频显示比例继续沿用。HH优化 的设置优先于旧设置，后续启动不重复迁移。首次合并将启动页设为“仅首次启动显示”，原“总是显示”设置保留；之后继续遵守用户对启动页显示的设置。

视频使用静音内联播放，音乐遵守背景音量。浏览器要求交互时，点击页面后重试播放；模式入口立即可用，视频加载或解码失败也可进入游戏。关闭预览、切换视频和进入游戏时清理媒体及播放重试监听。

自行添加的视频或音乐分别放入 `assets/startup/video/`、`assets/startup/music/`。具备文件读取权限时自动补充菜单，音乐支持 MP3 和 M4A；配套开场视频按 `开场-名称.mp4` 命名。

大厅按参考图的 2760×1256 坐标还原，整组等比适配窗口，不显示顶部通知横幅及顶部深色遮罩。保留 `孙尚香.mp4` 背景、媒体选择、背景欣赏和公告；旧的模式排序和左右翻转不再影响大厅。禁用启动美化后重启，使用游戏原有启动界面。

四个模式入口：斗地主 → `doudizhu`，排位赛 → `versus`（对决），经典场 → `identity`（身份），活动场 → `guozhan`（国战）。点击后等待模式配置存储完成，再清理媒体及缩放监听并重启；“总是显示启动页”也能直接进入所选模式。

底部“武将”打开现有武将界面，可搜索、切换武将包、查看详情并管理启用状态。关闭后返回大厅，保留视频背景；不进入对局或切换模式。启动时读取已导入的武将包及启用扩展的资料构建浏览视图，不提前执行游戏资料初始化。其余按钮支持鼠标、触屏和键盘激活，点击时短暂缩小并回弹，暂不触发功能或修改配置；减少动态效果时仅改变透明度。头像、昵称、货币及通知数量保留参考图的展示值，未连接账号系统。

`assets/startup/lobby/` 保存大厅素材，运行时不依赖 E 盘资源目录。原生图标及 HYXLSJ 字体来自 `E:\AI\sanguosha\extract\unity`，字体按大厅用字裁剪为 WOFF2。缓存客户端的卡面版本与参考图不同，参考图补齐四张卡面、活动横幅、头像及部分图标；每个素材的来源和裁剪区域记在 `lobby/sources.json`，可用 `tools/import-startup-lobby.py` 重新生成。界面布局与入口逻辑位于 `src/ui/startupLobby.js`，样式位于 `assets/startup/lobby.css`。

2.0.26 为默认 `孙尚香.mp4` 提供 1920×1080、30fps、H.264 的手机版本，完整保留约 9 秒循环画面，文件从 56,703,059 字节缩小至 5,047,444 字节。无需先升级旧更新器即可下载较小的媒体文件。更新器随后逐文件下载、校验和暂存，降低安卓全文件读取与 Base64 桥接的并发内存占用；完整缓冲区写入时不再额外复制。

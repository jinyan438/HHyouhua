# 启动界面美化

2.0.25 将缘伴随行的“启动界面美化”1.2.1 合并进 HH优化。视频、音乐、音效、字体和图片完整收录于 `assets/startup/`，不依赖原扩展目录，在线更新时一起校验和安装。原许可证保留于 `assets/startup/LICENSE`。

“扩展 → HH优化”提供启动美化开关、预览、背景视频、背景音乐和显示比例。默认启用，首次合并使用 `孙尚香.mp4`，之后保留用户在 HH优化 中选择的视频。支持六套背景视频、两段开场动画和七首背景音乐；网页无法读取目录时仍提供全部内置选项。

旧扩展从启用列表移除并停用，音乐选择、视频显示比例、模式顺序及左右布局继续沿用。HH优化 的设置优先于旧设置，后续启动不重复迁移。首次合并将启动页设为“仅首次启动显示”，原“总是显示”设置保留；之后继续遵守用户对启动页显示的设置。

视频使用静音内联播放，音乐遵守背景音量。浏览器要求交互时，点击页面后重试播放；模式入口立即可用，视频加载或解码失败也可进入游戏。关闭预览、切换视频和进入游戏时清理媒体及播放重试监听。

自行添加的视频或音乐分别放入 `assets/startup/video/`、`assets/startup/music/`。具备文件读取权限时自动补充菜单；配套开场视频按 `开场-名称.mp4` 命名。

原版模式布局、模式排序、背景欣赏、公告和布局保存入口继续保留。禁用启动美化后重启，使用游戏原有启动界面。

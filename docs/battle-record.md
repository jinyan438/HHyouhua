# 查看战绩

开启 HH 的 MVP 结算后，胜利、失败、平局及全场最佳画面右下方均可点击“查看战绩”。关闭战绩表回到打开前的画面；胜负继续 → 全场最佳继续 → 大厅的顺序保持不变。

表格按胜负、座次排列，包含存活与阵亡玩家，展示当前皮肤头像、昵称、武将、身份、击杀数、伤害分、治疗分、辅助分、总评分与 MVP。胜方红色、负方蓝灰色，自己所在行使用原版金色底图。胜负取当前模式的 `checkOnlineResult`，不以阵亡判断失败；无法确认的角色显示未定。平局单独显示。宽屏保留原布局，竖屏横向滚动查看列，多人表格支持滚动。

“总评分”表头可打开完整 HH 规则。“一键点赞”及逐行点赞仅作用于这次本地战绩，重复点击不累加，不向官方发送请求。可用时，“保存录像”导出本体使用的编码录像格式，仍可通过本体录像菜单导入；没有录制数据或正在播放录像时隐藏。原版的微信分享、举报和官方货币奖励依赖其服务端／SDK，本扩展未接入，因此不展示这些操作或虚构对应数值。

素材与原版逻辑来自 `E:\AI\sanguosha\sanguosha2`：

- `work/main.js`：`Vji.clickZhanji` 是带下划线的文字入口，`aps.OnOpenZhanJi()` 打开 `GameZhanJiWindow`，并保留原结算窗口；`ffs extends nZi` 创建战绩页，`hZi extends Zzt` 创建各行。原版按 `Result`、`SeatID` 排序，头像、胜败标志、金色本人行及 MVP 徽章来自 `gameResult` 图集。
- `work/rx_pathmap_full.json`：`1a73c9e0` → `/res/assets/gameResult/gameResult.atlas`；`fecbbcf6` → 同目录 `gameResult.png`。原文件从 `yoka.game_g_android_4.0.2.apk` 的 `assets/cache/https.__web.sanguosha.com_220_sgsolApp/` 提取。`assets/battle-record/` 保留两份原文件、65 张按原图集坐标还原的 PNG，以及记录尺寸、路径和 SHA-256 的 `sources.json`；可运行 `python tools/import-battle-record.py` 重提取。
- `CU.Read()` 从二进制协议读取五个 short 并分别除以 10；`CU.ReadProto()` 对 `kill_score`、`damage_score`、`heal_score`、`assist_score`、`mvp_score` 分别除以 10。`Result` 0 为胜、1 为负、2 为小胜（主公杀内奸有特例），`Grace` 等奖励也由协议给出。`hZi.SetResultData()` 直接显示这些值。检索全部 `main.js` 后，每个 snake_case 评分字段仅出现于协议声明和读取处，未找到官方服务器的计算公式，不能从客户端还原该公式。

本扩展使用 HH 已有的四个计分技能，通过 `battleRecordData.js` 统一计算，与 `mvpSettlement.js` 使用同一份快照。以显示单位计：

| 项目 | HH 本地规则 |
| --- | --- |
| 伤害分 | 使用伤害牌 +0.2；对敌方造成每点伤害 +0.3、单次上限 +1.5；击杀敌方 +0.3。内奸对其他角色造成伤害也计入，击杀非主公友方 +0.3 且免误杀扣分。 |
| 治疗分 | 为自己或友方回复每点体力 +0.2、单次上限 +1；来源为内奸时也计入。 |
| 辅助分 | 无懈可击 +0.2；非自身的多目标锦囊 +0.1；从敌方来源获得牌，获得者每张 +0.1；敌方来源导致弃牌，来源每张 +0.1；来源为内奸时不限制敌方关系。 |
| 局势分 | 起始 10；自己阵亡 −2；每名敌方阵亡 +0.2、友方阵亡 −0.2。 |
| 惩罚分 | 误杀友方 −0.5，内奸击杀非主公友方适用上述特例。 |
| 总评分 | 以上前三项加局势分减惩罚分，最低 0，保留一位小数。全体玩家按该分数选 MVP，同分沿用原玩家顺序。 |
| 击杀数 | 汇总本体各回合 `player.stat[].kill`，不从攻击分反推。 |

该规则是 HH 本地规则，不能视为官方服务器公式。所有结束统计只读玩家数据，不更改玩家数组，不在打开战绩时重新计分，不另发银两或地主豆。

验证包含素材哈希、阵亡队友获胜、模式判定失败的回退、评分与 MVP 一致、快照不可变、逐行／一键点赞、可导入录像结构、计分说明关闭、两个入口的焦点／遮罩恢复、完整结算流程及多次点击。另以实际本体 `game.over` 验证奖励、原始统计录像、原胜负记录及新战绩入口共存。

# HH优化

无名杀扩展，整合界面美化、游戏优化和全屏身份选将。默认设置来自用户于 2026-11-14 22:50:31 导出的 HH优化和十周年UI配置。

将本仓库内容放在游戏的 `extension/HH优化/` 目录，在扩展菜单中启用“HH优化”。需要无名杀 1.11.1 或更新版本。

在游戏的“扩展 → HH优化”中点击“检查扩展更新”，确认后会从本仓库的默认分支下载更新。更新按远程提交识别，支持同版本号下的代码修复。只下载发生变化的文件，校验通过后才安装；安装失败会恢复旧文件，意外中断后会在下次启动恢复。完成后点击“重启游戏”生效。需要联网及游戏文件读写权限。

更新临时文件、恢复备份放在 `.hh-update/`，已安装提交信息放在 `.hh-update-state.json`，均已加入 Git 忽略。更新器不会修改游戏保存的个人设置。

提交扩展修改前可运行：

```sh
node tools/build-update-manifest.mjs
node --test tests/*.test.mjs
git add .
git commit -m "描述本次修改"
git push
```

`update-manifest.json` 用于新安装时识别本地文件。之后的更新直接比较 GitHub 文件清单，不要求每次远程提交都重新生成清单。

# HH优化

无名杀扩展，整合界面美化、游戏优化和全屏身份选将。默认设置来自用户于 2026-11-14 22:50:31 导出的 HH优化和十周年UI配置。

将本仓库内容放在游戏的 `extension/HH优化/` 目录，在扩展菜单中启用“HH优化”。需要无名杀 1.11.1 或更新版本。

2.0.3 的“启用连斩特效”现播放一破「龙战于野」至七连「毁天灭地」的完整动画及对应音效，替换原来的旧播报音频和文字占位。保留原有击杀计数与回合清理规则，等待实际动画结束后继续结算。完整资源随扩展离线提供，运行库与原有动态皮肤隔离；详见 [连斩说明](docs/kill-combo.md)。

2.0.4 已提取标准包 32 种实体牌和军争包 10 种实体牌的原始卡牌动画。普通杀、雷杀、火杀和闪保留旧特效；过河拆桥和万箭齐发关闭特效。非延时锦囊在中央出牌位置播放，火攻缩小、决斗放大，顺手牵羊实际获得牌时播放；延时锦囊判定生效后播放。保留原有卡牌规则与语音，详见 [卡牌动画说明](docs/source-card-animations.md)。

2.0.5 修复顺手牵羊获得牌后因技能编译丢失外层变量而报 `shownSteals is not defined` 的问题，保留获得牌后播放及同一事件只播放一次的行为。

2.0.6 在“启用音频替换”中接入顺手牵羊顺走牌时的羊叫声及 23 张装备入槽时的原版音效，装备牌名和技能语音保留。声音独立于画面特效开关，并遵守游戏的全局音效与音量设置。无懈可击特效放大至原来的 1.6 倍。

2.0.7 濒死求桃按原座位顺序逐人询问，没有桃也会进入询问，真人可手动取消。当前角色显示与出牌思考同款的“桃 思考中…”提示，濒死武将牌固定显示原版红色“救我”标记。救援等待与“启用AI思考延迟”及其时长设置联动，实际出桃和转换选择不重复等待；详见 [求桃说明](docs/rescue-flow.md)。

2.0.8 新增默认开启的“开局AI主公盲狙”：离线身份局的 AI 主公按仇恨值与距离加权锁定目标，让卡牌和技能使用共同参考该目标。目标表现偏忠后重选，任何角色出现明确偏反倾向后结束盲狙；详见 [盲狙说明](docs/lord-blind-shot.md)。

2.0.9 盲狙改为动态启停：优先处理存活明反，明反死光后继续盲狙未表态角色；盲死反贼不会永久关闭机制。权重改为仇恨 90%、距离 10%，取消仇恨值压缩，让较远的高仇恨角色也能优先成为目标。

在游戏的“扩展 → HH优化”中点击“检查扩展更新”，确认后会从本仓库的默认分支下载更新。更新按远程提交识别，支持同版本号下的代码修复。只下载发生变化的文件，校验通过后才安装；安装失败会恢复旧文件，意外中断后会在下次启动恢复。完成后点击“重启游戏”生效。需要联网及游戏文件读写权限。

更新临时文件、恢复备份放在 `.hh-update/`，已安装提交信息放在 `.hh-update-state.json`，均已加入 Git 忽略。更新器不会修改游戏保存的个人设置。

2.0.2 修复安卓更新器的文件写入、截断及错误回调兼容问题。下载暂存、备份、安装和恢复都会读回校验；启动恢复失败时只暂停 HH优化的加载，保留修复入口。

手机已出现更新失败、重启无法进入游戏时，请先恢复到能启动的版本，移除旧 HH优化后导入 2.0.2 完整包，再重启。旧更新器本身有此兼容问题，本次请使用离线完整包安装。

提交扩展修改前可运行：

```sh
node tools/build-update-manifest.mjs
node --test tests/*.test.mjs
git add .
git commit -m "描述本次修改"
git push
```

`update-manifest.json` 用于新安装时识别本地文件。之后的更新直接比较 GitHub 文件清单，不要求每次远程提交都重新生成清单。

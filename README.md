# HH优化

无名杀扩展，整合界面美化、游戏优化和身份、斗地主全屏选将。默认设置来自用户于 2026-11-14 22:50:31 导出的 HH优化和十周年UI配置。

将本仓库内容放在游戏的 `extension/HH优化/` 目录，在扩展菜单中启用“HH优化”。需要无名杀 1.11.1 或更新版本。

“全屏选将”共用于本地身份及斗地主，复用开局武将牌、技能查看与确认交互；斗地主按三人座位显示地主/农民提示，保留各玩法原生候选、双将、叫地主及队友候选限制，详见 [选将界面说明](docs/character-selection.md)。

武将牌样式只保留“武将宽度”。以当前 136 像素样式为基准，左侧文字和勾玉固定对齐，画像、边框及发光向右适配；按素材的可见边缘补偿透明留边，牌面高度不变，详见 [宽度适配说明](docs/player-style-sizing.md)。

对局发光框已换为原版 OL `FX_PaiJu_ZuoWei` 的绿、黄橙、红、蓝四套光效，六种主题沿用原有状态切换。使用原始贴图、遮罩与材质颜色转换，左右边随武将宽度贴合外框，详见 [光框说明](docs/source-player-glow.md)。

可用及选中的主动技能按钮现使用原版 `fx_UI_AnNIu_ZhuDong` 金色发光与闪烁星点，六种主题共用，不可用时关闭；保留技能文字、标记与点击功能，详见 [按钮光效说明](docs/source-active-skill-glow.md)。

上下移动及排序卡牌的弹窗现使用原版 2025 技能窗口素材，标题与牌区居中，纵向行名、牌面及空槽对齐；“更换光标+loading框”的最后一个样式共用此背景，并随内容扩高，详见 [移牌弹窗说明](docs/source-move-dialog.md)。

武将名现复用原版 `FZLBGBK` 常规字体，势力字居中放大 10%，适用于对局、开局选将和武将详情，详见 [字体说明](docs/source-general-font.md)。

AI 思考进度条统一使用客户端圆头细条、底槽和末端光效，出牌、响应、技能选择、无懈可击及求桃共用这套样式。进度条位于武将牌内部底部、边框上方，随牌宽适配；“出牌 思考中”位于边框下方。满条固定代表 15 秒，按真实经过的时间平滑缩短：实际思考 3 秒只消耗 20%，思考结束后移除剩余进度条。“出牌 思考中”复用原出牌提示样式，仅在实际 AI 思考等待期间显示；交互结算期间不显示，也不添加替代提示。连续选择各自计时，快速操作只显示进度条，仍遵守原有思考时长及提示开关。

无懈可击询问及相关技能子选择期间，所有其他 AI 同步显示思考进度与提示，共用起始时间并一起结束。玩家没有无懈可击或转换技能时，也不会因只有响应者显示思考而暴露其手牌；显示不依赖各角色的响应能力。

玩家进度条开启后，每个本地手动操作独立计时，默认 15 秒。超时优先取消或不响应，强制选择由原生默认逻辑完成；连续 3 次超时进入托管，完成手动选择或取消托管后清零。暂停时停止计时，联机沿用房间规则；“操作时限”替换原来的进度条速度设置，详见 [玩家超时说明](docs/player-action-timer.md)。

“部件管理 → 进度条”新增“OL客户端进度条”，使用 OL 客户端 `gameBase` 图集中的方头黄色主进度条、底槽与末端光效，按原版 748×15 布局显示，宽度随窗口适配，沿用操作时限及进度条高度设置。当前出牌、响应、无懈可击等操作提示居中显示在进度条上，文字底部与条底对齐，并随操作内容及进度条高度同步更新。

“装备牌移动优化”开启后，装备牌先在目标武将牌左上角展示，再缩小进入实际装备栏左侧。普通使用、技能直接置入（含 `hh_sp3` 吕玲绮“妆戎”）、装备转移及虚拟装备共用这套动画，停留 0.3 秒、缩小 0.45 秒。动画副本独立计时清理，装备被取消、替换或跳过原生移动回调时也不会残留；拆除及弃置装备仍沿用普通弃牌动画。

2.0.3 的“启用连斩特效”现播放一破「龙战于野」至七连「毁天灭地」的完整动画及对应音效，替换原来的旧播报音频和文字占位。保留原有击杀计数与回合清理规则，等待实际动画结束后继续结算。完整资源随扩展离线提供，运行库与原有动态皮肤隔离；详见 [连斩说明](docs/kill-combo.md)。

2.0.4 已提取标准包 32 种实体牌和军争包 10 种实体牌的原始卡牌动画。普通杀、雷杀、火杀和闪保留旧特效；过河拆桥和万箭齐发关闭特效。非延时锦囊在中央出牌位置播放，火攻缩小、决斗放大，顺手牵羊实际获得牌时播放；延时锦囊判定生效后播放。保留原有卡牌规则与语音，详见 [卡牌动画说明](docs/source-card-animations.md)。

2.0.5 修复顺手牵羊获得牌后因技能编译丢失外层变量而报 `shownSteals is not defined` 的问题，保留获得牌后播放及同一事件只播放一次的行为。

2.0.6 在“启用音频替换”中接入顺手牵羊顺走牌时的羊叫声及 23 张装备入槽时的原版音效，装备牌名和技能语音保留。声音独立于画面特效开关，并遵守游戏的全局音效与音量设置。无懈可击特效放大至原来的 1.6 倍。

2.0.7 濒死求桃按原座位顺序逐人询问，没有桃也会进入询问，真人可手动取消。当前角色显示与出牌思考同款的“桃 思考中…”提示，濒死武将牌固定显示原版红色“救我”标记。救援等待与“启用AI思考延迟”及其时长设置联动，实际出桃和转换选择不重复等待；详见 [求桃说明](docs/rescue-flow.md)。

2.0.8 新增默认开启的“开局AI主公盲狙”：离线身份局的 AI 主公按仇恨值与距离加权锁定目标，让卡牌和技能使用共同参考该目标。目标表现偏忠后重选，任何角色出现明确偏反倾向后结束盲狙；详见 [盲狙说明](docs/lord-blind-shot.md)。

2.0.9 盲狙改为动态启停：优先处理存活明反，明反死光后继续盲狙未表态角色；盲死反贼不会永久关闭机制。权重改为仇恨 90%、距离 10%，取消仇恨值压缩，让较远的高仇恨角色也能优先成为目标。

2.0.10 武将牌中央的普通技能提示现使用原版墨迹动画及书法字体，替换旧的飞入文字，按原版节奏单次播放；详见 [技能提示说明](docs/source-skill-popup.md)。

2.0.11 矩形技能标记已接入原版灰色状态框和金色可查看框，完整显示技能名及 `[数量]`，保留原有查看和计数功能；详见 [标记说明](docs/source-skill-marks.md)。

2.0.12 技能标记名称与数量现合为同一行文字，统一字体、字号和行高；金色按实际存牌/查看定义实时识别，更新时纠正旧分类。已用破军、权计和屯田的本机技能定义验证。

2.0.13 判定改为沿用游戏原生结算，保留异步回调入牌及清理顺序；技能关联标记补齐存储键。屯田的非红桃判定牌入田、数量及详情卡牌已通过完整流程检查。

2.0.14 右上角菜单新增“武将”入口，打开全屏武将界面。左侧按武将包分类，右上角按名字、编号或技能搜索，并可筛选已启用/已禁用武将。点击查看画像和技能，长按约 0.6 秒切换当前模式禁将设置，禁用武将显示灰色；详见 [武将界面说明](docs/character-browser.md)。

2.0.15 武将牌直接复用开局选将的同一外观组件及开局实际记录的宽高比例，沿用当前主题的金龙边框、势力栏、名字与体力勾玉，列表与详情保持一致，不显示换将按钮。

2.0.16 武将界面与设置页共用武将包开关和禁将数据。长按左侧武将包可开启或关闭，关闭整包时半透明显示并保留个人禁将；各分包按原生分组排列，使用原版金色分隔条显示名称、数量与开关，不添加徽章或集齐奖励。分包开关与设置页一样批量切换该组禁将，保存后同步刷新设置页。

2.0.17 武将筛选改为同款金棕色下拉菜单，直接在按钮下方展开。详情武将放大，右侧复用原版页签、主动/被动标识和台词按钮，可试听当前技能语音；下方皮肤缩略图支持切换已安装及注册形象并保存选择，保留当前武将牌比例、主题与禁将设置。

2.0.18 详情武将按左侧实际可用区域计算尺寸，保持开局牌面比例放大并贴齐底部。根据牌面真实渲染宽度校准缩放，修复游戏或主题额外缩放后仍然偏小的问题；横竖屏切换和窗口变化时重新计算。

2.0.19 斗地主复用身份局全屏选将，武将宽度设置自动适配边框、光效、画像和勾玉。武将名使用原版字体并放大，OL 势力字与名字共用一条竖排中心线；详情大图始终正常显示颜色。

2.0.20 身份和斗地主开局新增“点将”牌位，点击可从当前已加载的可见武将中任选，支持武将包筛选及名字、编号、技能搜索。选中后显示技能，再点牌面确认；双将可以连续点选两名武将。

2.0.21 修复开局长按换将后无法确认的问题。点将列表内第一次点击显示该武将的技能和“确认选择”，第二次点击直接确认；点空白区域取消待确认状态并收起技能。

在游戏的“扩展 → HH优化”中点击“检查扩展更新”，确认后会从本仓库的默认分支下载更新。更新按远程提交识别，支持同版本号下的代码修复。只下载发生变化的文件，校验通过后才安装；安装失败会恢复旧文件，意外中断后会在下次启动恢复。完成后点击“重启游戏”生效。需要联网及游戏文件读写权限。

更新临时文件、恢复备份放在 `.hh-update/`，已安装提交信息放在 `.hh-update-state.json`，均已加入 Git 忽略。更新器不会修改游戏保存的个人设置。

2.0.2 修复安卓更新器的文件写入、截断及错误回调兼容问题。下载暂存、备份、安装和恢复都会读回校验；启动恢复失败时只暂停 HH优化的加载，保留修复入口。

手机已出现更新失败、重启无法进入游戏时，请先恢复到能启动的版本，移除旧 HH优化后导入 2.0.2 完整包，再重启。旧更新器本身有此兼容问题，本次请使用离线完整包安装。

提交扩展修改前可运行：

```sh
node tools/build-update-manifest.mjs
node --test tests/*.test.mjs
git add .
git commit -m "描述本次修改"
git push
```

`update-manifest.json` 用于新安装时识别本地文件。之后的更新直接比较 GitHub 文件清单，不要求每次远程提交都重新生成清单。
